# Repository instructions

Read and follow [AGENTS.md](AGENTS.md) before working in this repository. It is
the authoritative source for repository conventions, native execution and
deployment requirements, file placement, and validation rules.

To resume work, start with [the resume note](.maintainer/resume.md): current
state, decisions in force, open items and the next step. That file is local and
gitignored; if absent, ask the maintainer for the current scope. Read the private
environment notes referenced by AGENTS.md before remote access or validation.
